2. Explain tight coupling vs loose coupling and what does Spring IOC do?
   Tight coupling means that classes are highly dependent on each other. One class explicitly instantiates or configures another, making the code rigid, hard to test, and hard to maintain.
   Loose coupling means that classes depend on abstractions (interfaces) rather than concrete implementations. This makes the system more flexible, testable, and maintainable.
Spring's Inversion of Control (IoC) container:
Manages object creation (beans)
Injects dependencies automatically
Inverts control: instead of classes controlling their dependencies, Spring does it.
3. What is MVC pattern?
   MVC stands for Model-View-Controller, a design pattern used to separate an application into three interconnected components, improving modularity, testability, and separation of concerns.
4. What is Front-Controller?
   A Front Controller is a design pattern where a single handler (controller) processes all incoming requests to a web application before dispatching them to appropriate handlers (like controllers, actions, or views).
   Client sends request (e.g. GET /users)
   
5. Explain DispatcherServlet and how it works.
   The DispatcherServlet is the core of the Spring MVC framework. It acts as the Front Controller, meaning it handles all HTTP requests coming into the application, routes them to the appropriate components, and generates a response.
   DispatcherServlet receives it (acts as the Front-Controller)
   Finds the correct controller
   Matches URL + HTTP method → calls controller method
   Controller processes the request
   May call service/model, prepares data
   Controller returns a view name + model data, or just data (JSON)
   DispatcherServlet handles the result
   If view name → passes to ViewResolver
   If data → uses HttpMessageConverter
   Renders response
   View becomes HTML
   data becomes JSON
   Response sent to client
6. What is JSP and What is Model And View？
   JSP (JavaServer Pages) is a server-side technology used to create dynamic web pages using Java. It's a view technology in Java-based web applications, similar to Thymeleaf or FreeMarker in Spring.
   ModelAndView is a Spring class used to hold both the model (data) and the view (page) together.
