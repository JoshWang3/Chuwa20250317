2. Explain monolithic architecture, service oriented architecture and Micro service architecture.

#### **Monolithic Architecture**

* All components (UI, business logic, DB access) are in a single deployable unit.
* Example: A Spring Boot app that contains user login, product catalog, order processing all in one JAR/WAR.
* **Pros**:

    * Easy to develop/test at the beginning
    * Simple deployment
* **Cons**:

    * Difficult to scale specific modules
    * Changes in one part can affect the whole system

#### **Service-Oriented Architecture (SOA)**

* Uses services to support software components.
* Communicates over an enterprise service bus (ESB).
* Example: SOAP-based services exchanging XML over HTTP.
* **Pros**:

    * Better separation than monolith
    * Centralized governance
* **Cons**:

    * ESB becomes a single point of failure
    * Heavyweight and tightly coupled

#### **Microservice Architecture**

* Decomposes application into small, independent services.
* Communicates via REST/gRPC/events.
* Example: `UserService`, `OrderService`, `InventoryService` as independent Spring Boot applications.
* **Pros**:

    * Scalability, resilience, independent deployments
* **Cons**:

    * Complexity in communication, deployment, data consistency

4. Explain Resilience patterns? Explain circuit breaker with Spring Cloud Hystrix code example.

#### **Resilience Patterns**:

* **Circuit Breaker**: Stop calling a failing service temporarily
* **Retry**: Retry failed operations with backoff
* **Timeout**: Avoid hanging calls
* **Bulkhead**: Isolate failures
* **Fallback**: Return a default response


#### **Circuit Breaker with Spring Cloud Hystrix**:

```java
@Service
public class ProductService {

    @HystrixCommand(fallbackMethod = "getFallbackProduct")
    public Product getProductById(String id) {
        // Call to external service
        return restTemplate.getForObject("http://inventory-service/products/" + id, Product.class);
    }

    public Product getFallbackProduct(String id) {
        return new Product(id, "Default Product", 0);
    }
}
```

5. Explain load balancing algorithms.

#### Common Algorithms:

* **Round Robin**: Cycles through instances
* **Random**: Randomly selects
* **Weighted Round Robin**: Prefer stronger nodes more
* **Least Connections**: Chooses instance with fewest active connections

#### Spring Cloud LoadBalancer (Replaces Ribbon):

Auto-configures based on properties like `@LoadBalanced RestTemplate`.
