# 3. Compare let vs var , explain variable hosting with your own code examples.

| Feature       | `var`                                        | `let`                                       |
| ------------- | ---------------------------------------------- | --------------------------------------------- |
| Scope         | Function-scoped                                | Block-scoped                                  |
| Hoisting      | Yes, initialized as `undefined`              | Yes, but in**Temporal Dead Zone (TDZ)** |
| Redeclaration | Allowed                                        | **Not allowed** in the same scope       |
| Global Object | Creates a property on `window` (in browsers) | Does**not** create a global property    |

```javascript
function testVar() {
  if (true) {
    var x = 1;
  }
  console.log(x); // 1 — because var is function scoped
}

function testLet() {
  if (true) {
    let y = 2;
  }
  console.log(y); // ReferenceError — let is block scoped
}
```

```javascript
var a = 5;
var a = 10; // OK

let b = 5;
let b = 10; // SyntaxError: Identifier 'b' has already been declared
```

# 4. Explain closure with code example

A closure is created when a function remembers and accesses variables from outside its own scope, even after the outer function has finished executing.

```javascript
function outer() {
  let count = 0;

  function inner() {
    count++;
    console.log(count);
  }

  return inner;
}

const counter = outer(); // `outer` runs and returns `inner`
counter(); // 1
counter(); // 2
counter(); // 3

```

# 5. Explain Callback Hell with code example

Callback hell happens when there are nested callbacks that make code very difficult to read and maintain.

```javascript
function registerUser(callback) {
  setTimeout(() => {
    console.log('User registered');
    callback();
  }, 1000);
}

function sendWelcomeEmail(callback) {
  setTimeout(() => {
    console.log('Welcome email sent');
    callback();
  }, 1000);
}

function loginUser(callback) {
  setTimeout(() => {
    console.log('User logged in');
    callback();
  }, 1000);
}

function redirectToDashboard() {
  setTimeout(() => {
    console.log('Redirected to dashboard');
  }, 1000);
}

registerUser(() => {
  sendWelcomeEmail(() => {
    loginUser(() => {
      redirectToDashboard();
    });
  });
});
```

# 6. Explain Promise, Async, Await with code examples.

These are all useful to handle a callback hell situation.

Promise is a value that **may be available**. It has three states:

* **Pending** : initial state
* **Fulfilled** : operation completed successfully
* **Rejected** : operation failed

```javascript
function getData() {
  return new Promise((resolve, reject) => {
    setTimeout(() => {
      const success = true;

      if (success) {
        resolve("Data received");
      } else {
        reject("Error fetching data");
      }
    }, 1000);
  });
}

getData()
  .then(result => console.log(result))   // Output: Data received
  .catch(error => console.error(error)); // If error: Error fetching data
javascript
```

`async` is used to define a function that always returns a promise.

```javascript
async function greet() {
  return "Hello!";
}

greet().then(msg => console.log(msg)); // "Hello!"
```

`await` is used inside an `async` function to block and wait for the results.

```javascript
function getUserId() {
  return new Promise(resolve => {
    setTimeout(() => resolve(42), 1000);
  });
}

async function main() {
  console.log("Fetching user ID...");
  const userId = await getUserId(); // waits here
  console.log(`User ID is: ${userId}`);
}
```

# 9. Explain how Javascript implement asynchronous non-blocking feature

1. Particularly: Event Loop, Macrotask, and Microtask with code samples.

There are three major components:

- The **Call Stack**
- **The **Event Loop****
- ****Task Queues** (Microtasks and Macrotasks)**

##### The event loop:

1. Executes synchronous code in the Call Stack
2. Checks the Microtask Queue and processes all microtasks
3. Then picks the next Macrotask and executes it
4. Repeats the loop indefinitely


| Feature       | Microtask Queue                                     | Macrotask Queue                                      |
| ------------- | --------------------------------------------------- | ---------------------------------------------------- |
| Examples      | `Promise.then()`, `queueMicrotask()`            | `setTimeout`, `setInterval`, `fetch` callbacks |
| Priority      | **Higher**                                    | Lower                                                |
| When Executed | After current stack,**before** next macrotask | After current stack & all microtasks                 |


```javascript
console.log('Start');

setTimeout(() => {
  console.log('Macrotask: setTimeout');
}, 0);

Promise.resolve().then(() => {
  console.log('Microtask: Promise.then');
});

console.log('End');
```
