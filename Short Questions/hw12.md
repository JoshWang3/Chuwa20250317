## Explain and compare following concepts, provide specific examples when doing comparison:

## Testing Related
### 1. Unit Testing
- Scope: single method/class
- Tests one small piece of code, like a method or functoin
- Make sure this part works by itself
- Example: Test a method that add two numbers `add(2, 3) should return 5`

### 2. Functional Testing
- Scope: whole feature
- Tests a full feature to se if it works as expected
- Check if the system behaves correctly with inputs and outputs
- Example: Test a login form: enter username and password, click login should go

### 3. Integration Testing
- Scope: component interaction
- Tests how multiple parts of the system work together.
- Catch bugs in how components or services talk to each other.
- Example: Login → fetch user data from DB → show profile — test the full chain.

### 4. Regression Testing
- Scope: whole system
- Re-run old tests to make sure new code didn’t break old features.
- Avoid probelm like “add a new feature, but now the feature is broken”
- Example: Fix a bug in the image display, but now the label function not work

### 5. Smoke Testing
- Scope: basic core flows
- Basic check to see if the system starts up and runs at all.
- Checks whether the system is alive after a new deployment
- Example: Checks that the app loads, login works, and main page shows up, but no deep test

### 6. Performance Testing
- Scope: speed test
- Checks how fast the system is under normal conditions.
- Ensure the system meets speed/responsiveness requirements.
- Example: Can the API handle 1000 users without slowing down?

### 7. Stress Testing
- Scope: extreme pressure
- Pushes the system past its limit to see how it breaks.
- Test system behavior under heavy load or failure.
- Example: Send 1 million requests in 5 minutes — see if the server crashes or recovers.

### 8. A/B Testing
- Scope: UX comparison 
- Show two versions of something to users to see which works better.
- Make data-based decisions.
- Example: Version A: red "Buy Now" button, Version B: green "Buy Now" button → Which one gets more clicks?

### 9. End-to-End (E2E) Testing
- Scope: Full user journey
- Tests the whole system from start to finish — like a real user.
- Make sure the entire app flow works.
- Example: User signs up → receive email → logs in → add product to chart → place order.

### 10. User Acceptance Testing (UAT)
- Scope: Real-word test
- Final check by real users or clients to make sure the system works as they expect before it goes live.
- Check if it meets business needs, not just technical ones.
- Example: User ask for an online tax filling protal. During UAT, clent do thins like 
  - login with test credentials
  - upload w2 form and 1099 form
  - enters some deductions
  - checks the estimated refund or amount owed
  - submits the return and receives a confimation email
  - review that the final tax summary matches their expection
  - overall works for clients

## Environment Related

### 1. Development
- **Purpose**: Developers build and test locally.
- **Features**: 
  - Where we write and test code locally.
  - Lots of logs, debug info.
  - Debug tools, hot reload, mocked dependencies.
  - Not stable — code changes often.

### 2. QA (Quality Assurance)
- **Purpose**: QA testers, automation testers test features from a user/business perspective.
- **Features**: 
  - Used to run functional, regression, and E2E tests.
  - Usually connected to test databases.
  - More stable than Dev.
  - Builds are promoted here from Dev once ready. (build is the latest, packaged version of applicatoin, all compiled and ready to run, in Java, this might be `.jar` or `.war` file, created after compiling and building the code)
  - Stable builds, testing tools, CI pipelines.

### 3. Pre-prod/Staging
- **Purpose**: Devs, QAs, Business teams do final test before go-live 
- **Features**: 
  - Mirrors Production as closely as possible:
    - Same config
    - Same DB schema
    - Sometimes even same data (but anonymized) 
  - UAT happens here.
  - May include load/stress testing.

### 4. Production (Prod)
- **Purpose**: Live environment used by end users.
- **Features**: 
  - Live, customer-facing system.
  - Real data, high monitoring, rollback protection.
  - High stability, high monitoring.
  - Changes must go through CI/CD, approvals, checks.

package com.example.testDemo;

import com.chuwa.redbook.dao.CommentRepository;
import com.chuwa.redbook.dao.PostRepository;
import com.chuwa.redbook.entity.Comment;
import com.chuwa.redbook.entity.Post;
import com.chuwa.redbook.exception.BlogAPIException;
import com.chuwa.redbook.exception.ResourceNotFoundException;
import com.chuwa.redbook.payload.CommentDto;
import com.chuwa.redbook.service.CommentService;
import org.modelmapper.ModelMapper;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.http.HttpStatus;
import org.springframework.stereotype.Service;

import java.util.List;
import java.util.stream.Collectors;

/**
 * @author b1go
 * @date 6/23/22 11:14 PM
 */
@Service
public class CommentServiceImpl implements CommentService {

    @Autowired
    private CommentRepository commentRepository;

    @Autowired
    private PostRepository postRepository;

    /**
     * use this modelMapper to replace the mapToDto, mapToEntity methods.
     */
    @Autowired
    private ModelMapper modelMapper;

    @Override
    public CommentDto createComment(long postId, CommentDto commentDto) {
        Comment comment = modelMapper.map(commentDto, Comment.class);
        // retrieve post entity by id
        Post post = postRepository.findById(postId)
                .orElseThrow(() -> new ResourceNotFoundException("Post", "id", postId));
        // set post to comment entity
        comment.setPost(post);

        // comment entity to DB
        Comment savedComment = commentRepository.save(comment);

        return modelMapper.map(savedComment, CommentDto.class);
    }

    @Override
    public List<CommentDto> getCommentsByPostId(long postId) {
        // retrieve comments by postId
        List<Comment> comments = commentRepository.findByPostId(postId);

        // convert list of comment entities to list of comment dto's
        return comments.stream().map(comment -> modelMapper.map(comment, CommentDto.class)).collect(Collectors.toList());
    }

    @Override
    public CommentDto getCommentById(Long postId, Long commentId) {
        // retrieve post entity by id
        Post post = postRepository.findById(postId)
                .orElseThrow(() -> new ResourceNotFoundException("Post", "id", postId));

        // retrieve comment by id
        Comment comment = commentRepository.findById(commentId)
                .orElseThrow(() -> new ResourceNotFoundException("Comment", "id", commentId));

        // 业务逻辑
        if (!comment.getPost().getId().equals(post.getId())) {
            throw new BlogAPIException(HttpStatus.BAD_REQUEST, "Comment does not belong to post");
        }

        return modelMapper.map(comment, CommentDto.class);
    }

    @Override
    public CommentDto updateComment(Long postId, Long commentId, CommentDto commentDtoRequest) {
        // retrieve post entity by id
        Post post = postRepository.findById(postId)
                .orElseThrow(() -> new ResourceNotFoundException("Post", "id", postId));

        // retrieve comment by id
        Comment comment = commentRepository.findById(commentId)
                .orElseThrow(() -> new ResourceNotFoundException("Comment", "id", commentId));

        // 业务逻辑
        if (!comment.getPost().getId().equals(post.getId())) {
            throw new BlogAPIException(HttpStatus.BAD_REQUEST, "Comment does not belong to post");
        }

        comment.setName(commentDtoRequest.getName());
        comment.setEmail(commentDtoRequest.getEmail());
        comment.setBody(commentDtoRequest.getBody());

        Comment updatedComment = commentRepository.save(comment);

        return modelMapper.map(updatedComment, CommentDto.class);
    }

    @Override
    public void deleteComment(Long postId, Long commentId) {
        // retrieve post entity by id
        Post post = postRepository.findById(postId)
                .orElseThrow(() -> new ResourceNotFoundException("Post", "id", postId));

        // retrieve comment by id
        Comment comment = commentRepository.findById(commentId)
                .orElseThrow(() -> new ResourceNotFoundException("Comment", "id", commentId));

        if (!comment.getPost().getId().equals(post.getId())) {
            throw new BlogAPIException(HttpStatus.BAD_REQUEST, "Comment does not belong to post");
        }

        commentRepository.delete(comment);
    }

    public static CommentDto commentServiceMapperUtil(Comment comment) {
        ModelMapper modelMapper = new ModelMapper();
        return modelMapper.map(comment, CommentDto.class);
    }
}

    private PostRepository postRepository;

    private ModelMapper modelMapper;

    // Inject Mocked Dependencies into Target Test class
    @InjectMocks
    private CommentServiceImpl commentService;

    private Post post;
    private Comment comment;
    private CommentDto commentDto;

    @BeforeEach
    void setup() {
        post = new Post();
        post.setId(1L);

        comment = new Comment();
        comment.setId(1L);
        comment.setPost(post);

        commentDto = new CommentDto();
        commentDto.setName("Elena");
        commentDto.setEmail("elena@test.com");
        commentDto.setBody("This is a great comment!");
    }

    @Test
    void createComment_ReturnsCommentDto() {
        // Arrange
        // Define how the mock dependencies behave when called on test
        when(postRepository.findById(1L)).thenReturn(Optional.of(post));
        when(modelMapper.map(commentDto, Comment.class)).thenReturn(comment);
        when(modelMapper.map(comment, CommentDto.class)).thenReturn(commentDto);
        when(commentRepository.save(comment)).thenReturn(comment);

        // Act
        CommentDto savedComment = commentService.createComment(1L, commentDto);

        // Assert
        assertThat(savedComment).isNotNull();
        verify(commentRepository).save(comment); // Verity this behavior
    }

    @Test

        when(commentRepository.findByPostId(1L)).thenReturn(Arrays.asList(comment));
        when(modelMapper.map(comment, CommentDto.class)).thenReturn(commentDto);

        List<CommentDto> resultComments = commentService.getCommentsByPostId(1L);

        assertThat(resultComments).isNotNull().hasSize(1).containsExactly(commentDto);
        verify(commentRepository).findByPostId(1L);
    }

    @Test
    void getCommentById_ReturnsCommentDto() {
        when(postRepository.findById(1L)).thenReturn(Optional.of(post));
        when(commentRepository.findById(1L)).thenReturn(Optional.of(comment));
        when(modelMapper.map(comment, CommentDto.class)).thenReturn(commentDto);

        CommentDto resultComment = commentService.getCommentById(1L, 1L);

        assertThat(resultComment).isNotNull();
    }

    @Test
    void getCommentById_ThrowsWhenCommentDoesNotBelongToPost() {
        Post otherPost = new Post();
        otherPost.setId(2L);
        comment.setPost(otherPost);

        when(postRepository.findById(1L)).thenReturn(Optional.of(post));
        when(commentRepository.findById(1L)).thenReturn(Optional.of(comment));

        assertThrows(BlogAPIException.class, () -> commentService.getCommentById(1L, 1L));
    }

    @Test
    void updateComment_UpdatesEntityAndReturnsMappedDto() {
        // Arrange
        CommentDto updatedRequest = new CommentDto();
        updatedRequest.setName("Alice");
        updatedRequest.setEmail("alice@test.com");

        when(commentRepository.findById(1L)).thenReturn(Optional.of(comment));

        when(commentRepository.findById(1L)).thenReturn(Optional.of(comment));
